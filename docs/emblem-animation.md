# Animated Exalted crest

The main homepage emblem and the desktop Timers & Events guild mark use `assets/exalted-crest-animated.gif`. The animation was generated with Higgsfield Seedance 2.0 on October 8, 2026, at the user's explicit request. The existing `assets/exalted-crest-512.png` was supplied as both the first and final frame to preserve the guild identity.

The six-second loop uses moving gold reflections, an emerald glow and a top-star glint. At the user's request it was converted to an infinitely looping GIF: 320 × 320, 12 frames per second and an optimized 128-color palette. The MP4 remains available as the source for future conversions. Original generation receipts and the full-resolution source are private working files under `output/exalted-emblem-higgsfield/` and must not be deployed.

The GIF is loaded directly by an image element and loops automatically, without a video player or JavaScript playback handling. The user explicitly requested removal of the pause control. Small navigation icons and sharing images remain static.

This is a format conversion of the user-requested Higgsfield animation. The project's default for new still images remains ChatGPT imagegen.
